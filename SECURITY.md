# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use **Report a vulnerability** in the repository's Security tab to send a private report to the maintainers.

Include the affected version, reproduction steps, impact, and any mitigation you already tested. You can expect an initial response within seven days. We will coordinate disclosure and credit with you after a fix is available.

## Supported versions

Security fixes target the latest published release. Prezzer produces static client-side presentations and does not include a hosted service, account system, or server runtime.
