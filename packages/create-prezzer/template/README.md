# {{title}}

A [Prezzer](https://github.com/hyperb1iss/prezzer) deck built with Bun and React.

```bash
bun install
bun dev
```

Edit `src/slides.tsx`, then press space to move through slides and beats. Press `g` for the grid, `n` for speaker notes, and `f` for fullscreen.

```bash
bun run check
bun run build
```

The build is one self-contained file at `dist/index.html`, ready to present offline or hand to anyone.
