# Code of conduct

Prezzer is a place for curious, direct, generous collaboration.

Treat people with respect. Critique ideas and code without attacking the person behind them. Make room for different backgrounds, communication styles, and experience levels. Harassment, discrimination, threats, sexualized conduct, and deliberate disruption are not welcome.

Maintainers may edit or remove contributions and restrict participation when behavior harms the community. Serious or sensitive concerns can be reported privately through the repository security contact rather than discussed in a public issue.

The goal is simple: build excellent software without making the room smaller for anyone else.
